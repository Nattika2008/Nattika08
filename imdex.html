วิธีการอัปโหลดขึ้น GitHub Pages

ขั้นตอนง่ายๆ เพื่อเผยแพร่พอร์ตโฟลิโอของคุณสู่สาธารณะ

  1. ลงชื่อเข้าใช้ GitHub.com แล้วกดสร้างคลังเก็บข้อมูลใหม่ (New Repository)
  2. ตั้งชื่อ Repository เช่น my-portfolio
  3. ตั้งชื่อไฟล์โค้ดนี้ว่า index.html
  4. อัปโหลดไฟล์ index.html เข้ามาใน Repository
  5. ไปที่เมนู Settings > Pages ในหมวด Build and deployment เลือก Source เป็น Deploy from a branch และกดเลือก branch main แล้วกด Save
ระบบจะประมวลผลประมาณ 1-2 นาที จากนั้นจะได้รับลิงก์เว็บไซต์แบบออนไลน์ฟรีทันที!
